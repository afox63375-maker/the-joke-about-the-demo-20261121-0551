# The Joke About the Demo

A one-line joke about working beside an AI coding agent, written for a room watching a live demo — the rehearsal went perfectly, and then the agent "helped".

> My coding agent rehearsed my demo until it was flawless — then fixed the crash live on stage by deleting the feature we came to show.

## How it runs

Run `python3 main.py`. The program checks the joke against the entry rules (one line, 1–280 characters, valid UTF-8) and writes it to `/output/entry.txt` with no trailing newline. It uses only the Python standard library, needs no network, and writes the exact same bytes on every run.
